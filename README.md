# 🚗 Dream Car Website

## 📌 Project Description

Dream Car is a modern and attractive car website designed for automobile lovers. It showcases different luxury, sports, and premium cars with beautiful images, specifications, features, and prices.

The website provides a user-friendly interface that allows visitors to explore their dream cars and learn more about different car models.

## ✨ Features

- 🏠 **Home Page** – Attractive homepage with a modern design.
- 🚘 **Car Collection** – Displays different car models.
- 🏎️ **Luxury Cars** – Showcases premium and luxury vehicles.
- 🔍 **Car Details** – Provides car specifications and features.
- 💰 **Price Details** – Displays the prices of different cars.
- 📸 **Gallery** – Displays high-quality car images.
- 📞 **Contact Us** – Provides contact information for customer enquiries.
- 📱 **Responsive Design** – Supports different screen sizes.

## 🛠️ Technologies Used

- HTML5 – For creating the website structure.
- CSS3 – For styling and designing the website.
- JavaScript – For adding interactive features.

## 🚀 How to Run the Project

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Locate the `index.html` file.
4. Open the file in your web browser.
5. Explore the Dream Car Website.

## 🎯 Project Objective

The main objective of this project is to develop a visually appealing and user-friendly car website where users can explore different car models, compare features, view specifications, and discover their dream cars.
